# Support

*[Français ci-dessous ⬇️](#assistance)*

- **How do I…?** Start with the built-in documentation (sidebar › *Documentation*) and the [README](README.md). Questions are welcome as [issues](https://github.com/rodolphe37/easy-ci/issues/new/choose) using the *Question* template.
- **Found a bug?** Open a [bug report](https://github.com/rodolphe37/easy-ci/issues/new?template=bug_report.yml) with your version (Settings › Updates), operating system and install method.
- **Have an idea?** Open a [feature request](https://github.com/rodolphe37/easy-ci/issues/new?template=feature_request.yml).
- **Security issue?** Do not open a public issue — follow [SECURITY.md](SECURITY.md).

Easy CI is maintained on personal time: responses may take a few days. Clear reports with reproduction steps get answered fastest.

# Assistance

- **Comment faire… ?** Consultez la documentation intégrée (barre latérale › *Documentation*) et le [README](README.fr.md). Les questions sont bienvenues en [issue](https://github.com/rodolphe37/easy-ci/issues/new/choose) avec le modèle *Question*.
- **Un bug ?** Ouvrez un [signalement](https://github.com/rodolphe37/easy-ci/issues/new?template=bug_report.yml) avec votre version (Paramètres › Mises à jour), votre système et votre méthode d'installation.
- **Une idée ?** Ouvrez une [demande de fonctionnalité](https://github.com/rodolphe37/easy-ci/issues/new?template=feature_request.yml).
- **Une faille de sécurité ?** Pas d'issue publique : suivez [SECURITY.md](SECURITY.md).

Les issues peuvent être rédigées en français ou en anglais.
